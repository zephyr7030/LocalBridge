  HEALTH_LISTEN_ADDR	Health/admin listen address; use :0 to request an ephemeral port (optional)
  HEALTH_UNIX_SOCKET	Health/admin Unix socket path; when set, tunnel-client does not bind TCP for health/admin (optional)
  HEALTH_URL_FILE	Write the resolved health base URL after startup; recommended with HEALTH_LISTEN_ADDR=:0 or HEALTH_UNIX_SOCKET (optional)
  ALLOW_REMOTE_UI	Set to true to allow non-loopback access to the embedded web UI (optional)
  OPEN_WEB_UI	Set to true to open the embedded web UI in a browser on startup (optional)
  ADMIN_UI_LOG_BUFFER_EVENTS	Recent log-event capacity for the embedded web UI and export archive (optional)
  CLOUDFLARED_TUNNEL_TOKEN	Pre-provisioned remotely managed Cloudflare Tunnel token; enables bundled cloudflared supervision (optional)
  CLOUDFLARED_MANAGED	Fetch the managed Cloudflare Tunnel runtime token from the control plane on startup (optional)
  CLOUDFLARED_PATH	Advanced override for the bundled cloudflared executable path (optional)
  CLOUDFLARED_READY_TIMEOUT	Maximum startup wait for bundled cloudflared readiness (optional)
  CA_BUNDLE	Path to a PEM CA bundle used for outbound TLS connections (additive to system trust) (optional)
  MCP_EXTRA_HEADERS	Static headers for outbound MCP HTTP requests to the configured MCP server origin; values accept env:VAR or file:/path (optional)
  MCP_DISCOVERY_EXTRA_HEADERS	Static headers for MCP discovery/probe requests to the configured MCP server origin; values accept env:VAR or file:/path (optional)
  MCP_CLIENT_CERT	Path (or env:VAR) to PEM client certificate for MCP mTLS (optional)
  MCP_CLIENT_KEY	Path (or env:VAR) to PEM client private key for MCP mTLS (optional)
  PROXY_CHECK_INTERVAL	Interval between proxy connectivity checks (optional)
