LocalBridge G4 发布前仓库卫生与公开发布授权

用户明确授权以下一次性治理与执行调整：

1. 在 LB-018 Runtime Packaging 之前插入 LB-018PRE（Pre-release Repository Hygiene + Public Source Prep），并将 LB-018 改为依赖 LB-018PRE。
2. LB-018PRE 必须完成：全仓及 Git 历史敏感信息扫描；干净 checkout 可复现 release build；依赖锁定；LICENSE 与第三方许可证/NOTICE 核对；README、SECURITY、CONTRIBUTING、Issue/PR 模板；GitHub Actions；release 包内容清洁检查。
3. 本地合同包、治理状态机、授权记录、内部执行/审查模板和历史治理材料不得进入 GitHub 公开源码仓库。
4. 公开源码必须从经过 allow/deny 清洗的独立快照创建，并使用全新的 Git 历史；不得直接把当前私有治理仓库历史推到 GitHub。`.gitignore` 不能替代对已跟踪内部文件和历史的排除检查。
5. 公开仓库只保留产品源码、公开文档、构建/CI、安全、许可证以及公开开发所必要的材料；内部治理事实源继续仅保留在本地私有工作树。
6. LB-018PRE 完成后直接执行 LB-018；LB-018 完成后创建 GitHub 公共仓库并推送清洗后的公开源码快照与规范文件。
7. 不得借 LB-018PRE 修改产品功能或削弱现有安全/权限/发布 Gate；LB-019 仍负责 clean-machine/live release acceptance。
8. 现有 G3→G4 双 Gate 不得伪造：必须先完成修复后要求的 fresh G3 independent adversarial review，再记录本次用户明确声明的人工审核 PASS，方可解锁 G4/LB-018PRE。

本授权只用于本次 G4 前置仓库卫生、LB-018 打包及随后创建公开源码仓库的连续任务。该文件属于本地内部治理证据，必须被公开源码导出 denylist 排除。
