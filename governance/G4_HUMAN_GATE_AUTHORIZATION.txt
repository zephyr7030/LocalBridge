LocalBridge G3 → G4 人工实测细审核 Gate 用户授权

授权日期：2026-08-12（Asia/Singapore）
授权性质：用户直接治理指令；本文件仅用于在 Git 中固化该外部授权，不是授权来源本身。

用户要求：
1. G3 全部 PR 完成并通过独立对抗性智能体审查后，不得直接开启 G4。
2. G3 智能体审查 PASS 后，必须进入独立的“人工实测细审核” Gate；只有该人工 Gate 被审查智能体接受为 PASS 后，G4 / LB-018 才可 READY/开始。
3. 人工实测细审核期间，审查智能体有权质疑、拒绝直接采信、要求复核或独立验证执行智能体提供的任何结论、日志、截图、测试结果或解释。
4. 同一期间，审查智能体同样有权质疑、拒绝直接采信、要求复核或独立验证用户提供的任何事实性信息、测试描述、截图、结论或其他证据。用户和执行智能体的陈述均属于待验证证据，不自动构成 PASS 事实。
5. 若人工 Gate 发现阻塞缺陷，应回开相应 G3 PR，修复后重新经过 G3 独立对抗审查，再重新进入人工 Gate；不得绕过或沿用旧 PASS。
6. 执行智能体允许使用预授权，但每一项实际使用的预授权必须具体记录 `authorization_id`、`scope`、`actions`、`evidence_ref`、`recorded_by`、`user_audit_status`；用户负责审核这些具体授权记录。缺少任一字段，或 `user_audit_status != PASS` 的预授权，不得作为人工 Gate PASS 的有效依据。

本条用户指令同时授权一次且仅一次的紧随本证据提交之后的治理实现提交，用于实现上述 Gate。该治理实现仅可修改：治理合同、实时状态 schema/初始 Gate 字段、架构规则描述、组执行/最终审查文档、审查/执行模板或 skill、架构 Gate verifier 及其确定性测试，以及与这些治理事实直接对应的 FINAL_REVIEW/PROJECT_STATE 元数据。

禁止事项：
- 不得修改 LocalBridge 产品代码、runtime 实现或任何 LB-006 及其他普通 PR 的产品实现；
- 不得扩大任何普通 PR writable_paths；
- 不得把本授权复用于未来治理修改、未来 PR、未来 scope violation；
- 不得仅凭用户或执行智能体“说已通过”就将人工 Gate 标记 PASS。

本次授权在唯一的紧随治理实现提交完成后即失效。
